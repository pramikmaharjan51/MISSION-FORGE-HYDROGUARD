THE INVENTION / DESIGN CONCEPT

HydroGuard: a cooperative, adaptive satellite mission

A proposed small-satellite constellation would combine precipitation estimates, soil-moisture observations and thermal measurements. A ground-side planner would prioritize high-risk regions, request targeted revisits, and deliver simple, uncertainty-labelled information to local water managers.

  • Adaptive revisit: observation time shifts toward regions showing stronger change.
  • Store-and-forward: satellites retain observations when a ground-station link is unavailable.
  • Community action layer: data is translated into preparedness prompts, never automatic emergency declarations.
  • Open-data design: NASA datasets provide a reproducible baseline for testing.
DATA SOURCE: NASA POWER Daily API · PRECTOTCORR (corrected precipitation, mm/day) and T2M (2 m air temperature, °C). Data are gridded/model-assisted estimates, not a local rain-gauge reading. The signal compares two adjacent 30-day windows and must not be treated as a validated drought index or forecast. NASA POWER API documentation ↗
